# UCP Express (`@ucp/express`)

`@ucp/express` is a TypeScript package containing Express utilities:
middleware, healthchecks, auth, etc. generated by
[`gh:orionstar65/cookiecutter-typescript-package`][0].

## Server

`Server` creates a pre-configured Express app with health checks (`/`, `/alive`,
`/ready`), Prometheus metrics (`/metrics`), structured logging, and the default
middleware stack. Call `start()` to bind the HTTP server.

```ts
import Server from "@ucp/express/index.js";

const { app, start } = new Server();
app.get("/hello", (req, res) => res.json({ hello: "world" }));
start();
```

## Metrics

Every `@ucp/express` `Server`comes with all default Prometheus metrics
provided by the `prom-client` package.

Additionally, a `@ucp/express/middleware/MetricsMiddleware` adds metrics
tracking in-flight requests and their durations.

See [Metrics][1].

## Middleware

`@ucp/express` ships middleware as factory functions — each returns an Express
handler. The `Server` class mounts them in a fixed order:

1. **LoggingMiddleware** — structured request/response logging (bunyan)
2. **CORS + body parsing** — `cors()`, `express.json()`, `express.urlencoded()`
3. **ResponseMetadata** — attaches `x-request-id`, `x-response-id`, and timing
4. **MetricsMiddleware** — Prometheus golden-signal metrics (latency, traffic,
   saturation)
5. **AuthenticationMiddleware** — JWT bearer verification (currently disabled
   pending helm secrets)
6. _Per-route:_ **ValidationMiddleware**, **ConcurrencyLimitMiddleware**
7. **ErrorHandlerMiddleware** — catch-all error handler, mounted last in
   `start()`

Credential loading (`RemoteAccessMiddleware` or `LocalAccessMiddleware`) is
mounted by each connector between authentication and its route handlers.

See [Middlewares][2].
